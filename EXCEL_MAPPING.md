# Excel Report Mapping

## Sheet Name

**MS HSD** — preserve exact spelling for compatibility with existing workbook.

## Column Mapping

| Excel Column | Database Source | Notes |
|--------------|-----------------|-------|
| DATE | `invoices.invoice_date` | Formatted as date |
| Name of the Suppllier | `invoices.supplier_name` | **Preserve typo "Suppllier"** |
| BILL NO | `invoices.invoice_number` | |
| PRODUCT | `invoice_line_items.product` | One row per line item |
| INVOICE VALUE | `invoice_line_items.invoice_value` | |
| HSN CODE | `invoice_line_items.hsn_code` | |
| QUANTITY | `invoice_line_items.output_quantity` | Converted quantity |
| MEASURE | `invoice_line_items.output_measure` | e.g. Litres |

## Row Structure

Each line item produces one Excel row. Invoice header fields repeat per line item.

## Filters

Export includes only **APPROVED** invoices. Filters by date range, product, supplier.

## Rules

- Do not modify column names or order without explicit instruction
- Calculations come from database values, never regenerated by AI
- Quantity always uses `output_quantity` / `output_measure` (post-conversion)
